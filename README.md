# GeografiaApp

Aplicación web para gestionar países, departamentos y ciudades.

## Tecnologías

- Angular
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

## Funcionalidades

- CRUD de países.
- CRUD de departamentos.
- CRUD de ciudades.
- Gestión de relaciones entre entidades geográficas.

## Instalación y ejecución

**Backend**
```bash
cd backend
dotnet run --project Geografia.Api
```

**Frontend**
```bash
cd frontend/geografia-frontend
npm install
npm start
```

Configura la conexión a SQL Server antes de ejecutar la aplicación.
